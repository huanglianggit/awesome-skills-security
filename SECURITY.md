# Security Policy

This repository is a curated list and does not execute the linked projects. A bad
or compromised entry can still create supply-chain risk for readers, so reports are
handled according to their sensitivity.

## Private Reporting

Use [GitHub private vulnerability reporting](https://github.com/iFurySt/awesome-skills-security/security/advisories/new)
for:

- an entry that currently distributes malware or steals credentials;
- a compromised project, maintainer account, release, or download URL;
- a link that redirects to malicious content; or
- a repository issue that could expose reporters or users to active harm.

Include the affected entry, evidence, likely impact, and any safe mitigation. Do not
attach live credentials or executable malware.

## Public Corrections

Use the correction issue template for broken links, stale descriptions, license
changes, false claims, or non-sensitive removal requests.

## Response

Confirmed active threats may be removed before the full investigation is complete.
The listing can be restored after the upstream project is demonstrably safe and the
relevant provenance has been re-verified.
