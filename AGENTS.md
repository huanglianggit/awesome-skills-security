# awesome-skills-security

This repository is a curated Awesome List for security tooling, research, and
operational guidance around AI Agent Skills.

## Source of Truth

- `README.md` contains the curated list and its taxonomy.
- `CONTRIBUTING.md` defines inclusion, review, and description requirements.
- `SECURITY.md` defines private reporting for malicious or compromised resources.

## Working Rules

- Verify every external link and describe the project from primary sources.
- Require an explicit license for entries presented as open source.
- Put hosted, proprietary, and source-available resources in clearly labeled
  sections.
- Keep descriptions factual and avoid unverified marketing claims.
- Do not add direct installation commands or live malware links.
- Treat scanner verdicts as evidence, not proof of safety.
- Update the `Last reviewed` date only when the list is meaningfully re-verified.
- Keep changes focused; this repository does not need application scaffolding or
  placeholder CI.
